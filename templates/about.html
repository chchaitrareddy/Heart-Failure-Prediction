About The Project

Title: Heart Failure Prediction Using Classification Analysis Algorithms

This web application is built to predict whether an individual faces a risk of developing Coronary Heart Disease (CHD) over a 10-year period, based on key health metrics and clinical parameters.

📊 Dataset Overview

The system utilizes the famous Framingham Heart Study Dataset, an ongoing cardiovascular cohort study conducted on residents of Framingham, Massachusetts. The target outcome variable is TenYearCHD (where 1 signifies High Risk of heart disease in 10 years and 0 signifies Low Risk).

🌲 Machine Learning Algorithm

We use the Random Forest Classifier, an ensemble learning method that constructs multiple decision trees during training and outputs the majority class vote across all individual trees. Random Forest is ideal for clinical datasets because of its resistance to overfitting and high predictive accuracy.

💻 Technology Stack

  • Python: Core programming language.
  • Flask: Lightweight web application server framework.
  • Pandas & NumPy: Data manipulation, missing value median imputation, and numerical array transformations.
  • Scikit-Learn: Machine learning library supplying the RandomForestClassifier model.
  • Python Pickle: Built-in object serialization for saving and loading binary model artifacts (model.pkl).
  • HTML5 & CSS3: Pure vanilla user interface styling (no heavy frontend dependencies or JavaScript frameworks).
